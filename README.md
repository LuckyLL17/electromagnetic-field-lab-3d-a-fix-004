# ElectroMag Lab · 3D

基于 React、Vite、TypeScript、Three.js 与 React Three Fiber 的专业 3D 可视化实验平台。

## 启动

```bash
npm install
npm run dev
```

开发端口：`5176`。

## 三维测量剖面

场景内挂载了一块可拖动的测量剖面（右侧面板「3D MEASUREMENT SECTION」）：

- **拖动**：抓住平面两侧的黄色手柄沿法向移动（拖动时自动暂停相机轨道控制）；
- **选点**：点击青色平面或右侧热图，读取该物理点的场强、单位场矢量、面内方向角与穿出角；
- **右侧展示**：二维场强采样热图、最大 / 平均场强、无效采样计数与选点方向。

### 世界坐标一致性

剖面中心状态为 `{ 法向轴 axis, 法向位移 offset }`，选点状态为**世界坐标点 (x, y, z)**，
采样与选点全部在物理世界坐标中进行（面内 (u,v) 网格坐标在采样边界经 `planePoint` /
`worldToPlane` / `sectionUV` 显式完成 world ↔ field 转换）。测量剖面挂在场源演示
旋转 group **之外**，因此场源转动、切换场型、改变激励强度、旋转 / 缩放相机都不会
重置或平移剖面——它始终指向同一物理位置；拖动剖面时选点标记钉住同一物理点不跟随，
松手后若该点已越出当前剖面（法向偏离或面内越界）则清除选点。
结果签名 `axis|offset|n|size|mode|strength` 也不含任何相机量。

### 实时重算 vs 缓存（明确取舍）

| 场景 | 策略 |
| --- | --- |
| 拖动中 | 同步重算 28² 粗采样（单帧完成，绝不显示过期帧） |
| 停止 140ms 后 | 分块异步、可中断的精细采样（48²–128² 可选） |
| 再次回到同一物理位置 | 命中 LRU 缓存，零重算 |
| 开始新拖动 / 切场型 / 改强度 / 改尺寸 | `AbortController` 立即取消在途精细任务；松手去抖后自动恢复 |
| 无效物理位置 / 越界 offset / 非法尺寸 | 拒绝计算并计数，不污染网格 |
| 显示区域尺寸变化 | 仅 CSS 拉伸 n×n 位图，不触发重算 |

过期结果有双保险：调度器 token 校验阻止写入缓存，UI 层仅在结果签名与当前物理位置
严格一致时才展示精细结果，否则回退实时粗采样。
